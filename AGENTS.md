# Agent Guidelines

- Keep reusable AI-OS configuration, Agent definitions, Skills, and design history in Git.
- Use Markdown as the canonical artifact format.
- Do not add course notes, research papers, project-specific data, or Obsidian knowledge-base content.
- Treat Zotero as the bibliographic source of truth and Obsidian as the long-term knowledge layer.
- Do not create standalone runtime Workflows, Agents, Skills, or integrations without an explicit request.
- Keep runtime orchestration inside the corresponding Agent and preserve historical Workflow designs under `archive/workflows/`.
