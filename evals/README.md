# Specialist Agent Evaluation Foundation

This directory contains a small, manual architecture-regression suite. It tests behavior rather than subject-matter coverage and is intentionally not a benchmark corpus.

Run the relevant prompt set from a disposable external Project after `scripts/sync-runtime.sh`. Record the Codex version, date, prompt, result, Skills observed, and any unexpected filesystem changes. Do not store Project source material here.

Available suites:

- [Learning Agent](learning-agent-prompts.md)
- [Research Agent](research-agent-prompts.md)
- [Writing Agent](writing-agent-prompts.md)
- [Coding Agent](coding-agent-prompts.md)
- [Modeling Agent](modeling-agent-prompts.md)
- [Zotero Integration](zotero-integration-prompts.md)
