# Visualization

## Design rationale

This skill adapts critical-path, scope-control, diagram-selection, and validation principles from the installed MIT-licensed VisualCave skill and mature Mermaid diagram skills such as [softaworks/agent-toolkit](https://github.com/softaworks/agent-toolkit/tree/main/skills/mermaid-diagrams). It changes the default from standalone HTML to Markdown-native, editable artifacts and avoids mandatory rendering dependencies. No source code or templates are copied.

## Input and output

- **Input:** structured concepts, relationships, processes, comparisons, or data, plus an optional target medium.
- **Output:** an appropriate Markdown table, Mermaid diagram, chart specification, or rendered artifact with an accessible summary.
