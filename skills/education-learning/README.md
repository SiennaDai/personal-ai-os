# Education Learning

## Design rationale

This skill adapts evidence-oriented patterns from [Education Agent Skills](https://github.com/GarethManning/education-agent-skills), including retrieval-first prompts, progressive hints, misconception diagnosis, confidence checks, and scaffold fading. It consolidates those patterns into one minimum reusable capability, adapts them for STEM coordination, and omits the source library's broader orchestration and metadata model. No source code or text is copied.

## Input and output

- **Input:** a learning target, learner response, misconception, practice need, or assessment goal.
- **Output:** an adaptive question, diagnosis, feedback, hint sequence, practice activity, or compact Markdown learning plan.
