# STEM Reasoning

## Design rationale

This skill is built from scratch because it encodes the requested reasoning style: motivation, formal definition, derivation, intuition, and application. The sequence is a default scaffold rather than a mandatory response template.

No external skill code is reused and no runtime dependency is added.

## Input and output

- **Input:** a STEM concept, problem, claim, proof, derivation, algorithm, or identified reasoning gap.
- **Output:** Markdown reasoning with explicit assumptions, stable notation, justified steps, checks, and an application or example when useful.
